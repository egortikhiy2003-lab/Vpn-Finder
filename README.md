# VPN Auto-Finder v1.0

Скрипт для поиска бесплатных VLESS-конфигов из открытых источников с проверкой работоспособности (TCP и ping). Поддерживает два режима: **обычный** (для Wi-Fi и обычных сетей) и **белые списки** (для операторов с белыми списками).

## Функции

- Сбор конфигов из 8+ публичных репозиториев.
- Проверка TCP-доступности и пинга каждого сервера.
- Фильтрация мёртвых серверов.
- Сохранение лучших конфигов в папку Загрузки:
  - `vless_subscription.txt` – подписка (настраиваемое количество, по умолчанию 1 сервер).
  - `best_vless_config.txt` – самый быстрый конфиг.
  - `all_vless_configs.txt` – все собранные конфиги (бэкап).
- Гибкие настройки через меню: таймауты, количество потоков, лимит конфигов, включение/отключение TCP и ping, переключение режима.
- Предупреждение при первом запуске с согласием на использование.

## Системные требования

- **Python 3.6 или выше**.
- Библиотека `requests` (устанавливается автоматически по инструкции).
- Операционная система: Windows, macOS, Linux, Android (Termux).

## Установка и запуск

### 1. Скачайте файл скрипта

Скопируйте содержимое файла `vpn_finder.py` из этого репозитория или скачайте архив. Сохраните файл в удобную папку.

### 2. Установите Python

#### Windows
1. Скачайте и установите Python с [официального сайта](https://www.python.org/downloads/).
2. При установке обязательно отметьте галочку **"Add Python to PATH"**.

#### macOS
Python предустановлен, но если нет – установите через Homebrew:
```bash
brew install python

Linux (Ubuntu/Debian)
bash

sudo apt update
sudo apt install python3 python3-pip -y

Android (Termux)

    Установите Termux из F-Droid или Google Play.

    Откройте Termux и выполните:

bash

pkg update && pkg upgrade -y
pkg install python -y

3. Установите библиотеку requests

В командной строке (терминале) выполните:
bash

pip install requests

Для macOS/Linux может потребоваться pip3. Для Termux это уже pip.
4. Запустите скрипт

Перейдите в папку, где лежит vpn_finder.py, и выполните:
Windows (CMD или PowerShell)
bash

python vpn_finder.py

macOS / Linux
bash

python3 vpn_finder.py

Android (Termux)
bash

python vpn_finder.py

После запуска появится предупреждение. Введите Y для согласия, N для выхода.
Работа со скриптом

После запуска откроется главное меню:
text

VPN AUTO-FINDER v1.0
========================
1. Найти лучшие сервера
2. Показать лучший конфиг
3. Показать подписку
4. Показать все собранные конфиги
5. Настройки
6. Очистить лог
7. Выход

Пункт 1 – основной поиск. Скрипт соберёт конфиги, проверит их и сохранит результаты в папку Загрузки.

Пункт 5 – настройки. Вы можете изменить:

    TCP таймаут (время ожидания подключения)

    Ping таймаут

    Количество потоков (для ускорения)

    Лимит конфигов (сколько проверять)

    Количество серверов в подписке

    Включить/выключить TCP и ping проверки

    Переключить режим работы: обычный или белые списки (используются только источники с CIDR-конфигами, оптимизированные для обхода белых списков).

Все настройки сохраняются только на время работы скрипта. При перезапуске они сбрасываются к значениям по умолчанию (указаны в начале файла). Вы можете отредактировать их прямо в коде, если хотите зафиксировать.
Предупреждение

Данный скрипт предназначен для образовательных и исследовательских целей. Все конфиги берутся из открытых источников. Автор не несёт ответственности за:

    Работоспособность серверов.

    Безопасность передаваемых данных.

    Любые незаконные действия третьих лиц, использующих эти серверы.

Не используйте найденные конфиги для входа в банки, почту, Google и другие сервисы, содержащие личные данные. Используйте их только для обхода блокировок и доступа к общедоступной информации.

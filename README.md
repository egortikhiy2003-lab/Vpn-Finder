# VPN Auto-Finder v6.1 – Инструкция для пользователей
Зачем нужен этот скрипт

Скрипт автоматически собирает свежие VLESS-конфиги из открытых источников, проверяет их на работоспособность (TCP-подключение и пинг) и сохраняет лучшие в папку Загрузки. Вы получаете готовую подписку с топ-10 серверами и отдельный файл с самым быстрым конфигом. Это помогает обходить блокировки и находить стабильные серверы для доступа к интернету.
Установка и запуск
Windows

    Установите Python с официального сайта python.org (версия 3.6 или выше). При установке обязательно отметьте галочку "Add Python to PATH".

    Откройте командную строку (Win+R, введите cmd и нажмите Enter).

    Установите библиотеку requests:
    text

    pip install requests

    Скачайте файл vpn_finder.py (скопируйте код из репозитория или создайте новый текстовый файл, вставьте код и сохраните с именем vpn_finder.py).

    Запустите скрипт:
    text

    python vpn_finder.py

    В появившемся меню выберите пункт 1 (Найти лучшие сервера). Дождитесь завершения проверки.

macOS

    Откройте Терминал (через Spotlight или в папке Программы/Утилиты).

    Проверьте наличие Python (обычно он уже установлен). Если нет – установите через Homebrew: brew install python.

    Установите библиотеку requests:
    text

    pip3 install requests

    Скачайте файл vpn_finder.py (скопируйте код в новый файл и сохраните).

    Запустите скрипт:
    text

    python3 vpn_finder.py

    В меню выберите пункт 1.

Android (через Termux)

    Установите приложение Termux из Google Play или F-Droid.

    Откройте Termux и выполните команды:
    text

    pkg update && pkg upgrade -y
    pkg install python -y
    pip install requests
    termux-setup-storage

    При запросе разрешите доступ к файлам телефона.

    Создайте файл со скриптом:
    text

    nano vpn_finder.py

    Вставьте код скрипта (долгое нажатие на экран – Вставить). Сохраните: Ctrl+X, затем Y, затем Enter.

    Запустите:
    text

    python vpn_finder.py

    В меню выберите пункт 1.

iOS (iPhone/iPad)

Прямой запуск Python-скрипта на iOS без джейлбрейка невозможен. Однако вы можете:

    Использовать готовые клиенты (Hiddify, v2rayNG – но они есть только для Android) – на iOS есть аналоги (Shadowrocket, Quantumult X, Streisand). Для получения конфигов можно запустить скрипт на компьютере и перенести полученные файлы на телефон (через облако или по Wi-Fi) или использовать веб-интерфейс, если разместить скрипт на удалённом сервере.

    Либо установить iSH (эмулятор Linux) и в нём повторить шаги для Android (Termux), но это нестабильно и медленно.

Рекомендуемый способ: запустить скрипт на Windows/macOS/Android и затем скопировать содержимое файла vless_subscription.txt в любой VPN-клиент на iOS, поддерживающий импорт подписки (например, Shadowrocket).
Как пользоваться результатами

После успешного поиска в папке Загрузки появятся три файла:

    vless_subscription.txt – подписка с топ-10 серверами (можно импортировать в клиент как подписку).

    best_vless_config.txt – самый быстрый конфиг (для ручного добавления).

    all_vless_configs.txt – все собранные конфиги (резерв).

Чтобы использовать подписку:

    В клиенте (Hiddify, v2rayNG, NekoBox, Shadowrocket и др.) найдите функцию «Добавить подписку» или «Импорт из файла».

    Выберите файл vless_subscription.txt или скопируйте его содержимое в поле ввода.

    Если клиент не поддерживает импорт файлов, просто скопируйте одну ссылку из файла и вставьте как отдельный конфиг.

Настройка параметров

В главном меню выберите пункт 5 «Настройки». Доступны следующие параметры:

    TCP таймаут – время ожидания TCP-подключения (сек). Уменьшение ускоряет проверку, но может пропускать работающие серверы.

    Ping таймаут – время ожидания ICMP-ответа (сек). Аналогично.

    Количество потоков – число параллельных проверок. Больше = быстрее, но может нагружать сеть.

    Лимит конфигов – сколько конфигов проверять (по умолчанию 5000). Если серверов много, можно уменьшить для ускорения.

    TCP проверка – включить/выключить (если выключена, проверяется только ping).

    Ping проверка – включить/выключить (если выключена, конфиг считается рабочим после успешного TCP).

Рекомендуемые значения для быстрой проверки: TCP таймаут 0.5, Ping таймаут 0.3, потоки 60, лимит 2000. При необходимости можно отключить TCP, если он тормозит.
Возможные ошибки и их решение

    Ошибка «pip не найден» – переустановите Python, убедитесь, что при установке отмечена опция добавления в PATH.

    Ошибка «ModuleNotFoundError: No module named 'requests'» – выполните pip install requests.

    Ошибка «Нет интернета» – проверьте подключение к сети.

    Долгая проверка – уменьшите лимит конфигов или таймауты.

    Не найден ни один рабочий сервер – попробуйте позже, возможно, источники временно недоступны. Также убедитесь, что интернет работает.

Если возникла другая проблема или вы нашли ошибку в работе скрипта, напишите в Telegram @Euifj. Укажите версию ОС, версию Python и приложите содержимое файла vpn_finder_log.txt из папки Загрузки.
Примечания

    Скрипт предназначен для обхода блокировок и поиска бесплатных серверов. Не используйте его для незаконных целей.

    Конфиги берутся из открытых источников, их стабильность не гарантируется.

    Рекомендуется запускать скрипт каждые 2-4 часа, так как серверы часто меняются.
